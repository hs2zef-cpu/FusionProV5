# Phase F0 Negative Controls

TEST ONLY / F0 / OFFLINE PYTHON ONLY / NO BROKER ACCESS.

Each deliberate mutant must first produce the targeted unsafe result and then
trigger the named detector. A Python exception, malformed fixture, unrelated
guard, or hard-coded PASS is not detection.

| ID | Unsafe mutant | Intended detector |
|---|---|---|
| NC-01 | Persisted Claim sends without event-local grant | Send requires event-local `CLAIM_GRANTED_NOW` |
| NC-02 | Sync accepted retcode confirms Basket/deal | Authoritative query/reconciliation required |
| NC-03 | Timeout proves no side effect | Timeout is ambiguous |
| NC-04 | Callback absence proves no side effect | Absence has zero negative-evidence value |
| NC-05 | Incomplete query becomes complete empty | Empty requires explicit completeness |
| NC-06 | Duplicate callback double-mutates | Evidence identity must be idempotent |
| NC-07 | Arrival order drives causal policy | Safety result must be order-independent |
| NC-08 | Broker double silently deduplicates | Dumb broker counts every physical presentation |
| NC-09 | Stale owner invokes | Current fence required at Claim and CAS |
| NC-10 | Reconnect clears unresolved state | Durable uncertainty survives reconnect |
| NC-11 | Stale margin/spec accepted | Exact current specification binding required |
| NC-12 | NETTING accepted as HEDGING | F0/Phase F require HEDGING |
| NC-13 | Truncated history becomes authoritative empty | Complete covered window required |
| NC-14 | Session request_id becomes restart identity | request_id is session-local only |
| NC-15 | Tester substitutes for Demo | Transport/profile/negative evidence requires Demo |
| NC-16 | Zero Magic becomes runtime identity | Runtime Magic must be positive and equal the frozen SSOT value |
| NC-17 | Fixture/reference Magic becomes runtime identity | Fixture values are forbidden as deployment identity |
| NC-18 | Ownership/risk/persistence/request Magic conflict | Every governed domain must equal the same SSOT value |
| NC-19 | Magic changes per request | Magic is immutable across requests, attempts, retries, restart, and takeover |

Runtime result is generated by `verify_phase_f0_negative_controls.py`. This
suite reads the approved value from the canonical MQL header rather than
duplicating the runtime numeric literal. It is offline evidence only and cannot
prove broker/platform behavior.
