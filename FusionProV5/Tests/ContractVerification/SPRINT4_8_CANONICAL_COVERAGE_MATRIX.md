TEST ONLY — NOT FOR PRODUCTION — NO BROKER ACCESS

Status: Candidate / In Review / Unlocked. Sprint 4 remains the authorized baseline.

Classification: A = authoritative semantic; B = derived but safety-relevant; C = diagnostic only; D = the object's own integrity digest. Every A/B field below is digest-bound. A `...DigestPreimage` serializer excludes only D to prevent recursion; a separate `...FullDTO` serializer includes D as ordinary reconstructive data. `payload_size` is A metadata for the checkpoint: it is measured from the body, bound by the checkpoint digest, and carried by the full DTO.

Canonical fields use ordered `name:type:length:value` encoding. `S48-CAN-SELF-01` through `S48-CAN-SELF-07` prove each own digest is excluded from its preimage but included in its full DTO. `S48-RT-DIGEST-MISSING-*` and `S48-RT-DIGEST-TAMPER-*` prove absent or altered embedded digests fail closed.
